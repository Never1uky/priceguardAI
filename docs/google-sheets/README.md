# Google Sheets — чеклисты PriceGuard AI

Готовые CSV для импорта в Google Таблицы: QA (Windows + macOS) и подготовка к Chrome Web Store.

## Быстрый старт

```bash
npm run sheets:generate
```

Файлы появятся в `docs/google-sheets/`.

---

## Создание таблицы в Google Sheets

### Вариант A — одна книга, несколько листов (рекомендуется)

1. Откройте [Google Sheets](https://sheets.google.com) → **Создать**
2. Назовите книгу: **PriceGuard AI — QA & CWS v2.20.8**
3. Для каждого CSV:
   - **Файл** → **Импорт** → **Загрузка**
   - Выберите файл из `docs/google-sheets/`
   - Тип разделителя: **Запятая**
   - **Расположение:** «Создать лист(ы)» / «Заменить текущий лист» (для первого — заменить, для остальных — новый лист)
   - Импортировать

| Порядок | CSV-файл | Имя листа |
|---------|----------|-----------|
| 1 | `01_Сводка.csv` | Сводка |
| 2 | `02_QA_Windows_macOS.csv` | QA Win+Mac |
| 3 | `03_CWS_Подготовка.csv` | CWS Подготовка |
| 4 | `04_CWS_Контент.csv` | CWS Контент |
| 5 | `05_CWS_Графика.csv` | CWS Графика |
| 6 | `06_CWS_Публикация.csv` | CWS Публикация |
| 7 | `07_CWS_Permissions.csv` | CWS Permissions |

4. На листе **QA Win+Mac**:
   - Выделите столбцы **I** (Windows) и **J** (macOS)
   - **Вставка** → **Флажок** (Checkbox)
5. На листах CWS выделите столбец **Готово** → вставьте флажки
6. Закрепите первую строку: **Вид** → **Закрепить** → **1 строку**
7. Включите фильтр: **Данные** → **Создать фильтр**

### Вариант B — поделиться с тестировщиком

1. **Настройки доступа** → «Все, у кого есть ссылка» → **Редактор** или **Комментатор**
2. Отправьте ссылку тестировщику
3. На листе **Сводка** заполните имя, даты, версии Chrome

## Лист «QA Win+Mac» — как тестировать

**Один тестировщик, две ОС:**

1. Создайте профиль Chrome **PriceGuard QA** на Windows и на Mac
2. Установите `priceguard-ai-v2.20.8.zip` (или `dist/`)
3. Пройдите строки с **Приоритет = P0** на обеих ОС
4. Ставьте флажок в **Windows** / **macOS** при PASS
5. При FAIL: **Статус** = FAIL, **Баг #** = номер в трекере, **Комментарий** = шаги воспроизведения

**Порядок прохождения (~3–4 часа на обе ОС):**

| Фаза | Время | Что |
|------|-------|-----|
| 0 | — | На машине разработчика (автотесты) |
| 1 | 15 мин | Smoke на Win, затем на Mac |
| 2 | 45 мин | WB + Ozon + YM |
| 3 | 90 мин | Уведомления, сравнение, AI, Premium |
| 5 | 30 мин | Edge cases |
| Sync | 20 мин | 3.26 — Win добавляет, Mac проверяет |

**Критерий готовности к релизу:**

- Все **P0** + **Обязательно = Да** — PASS на **Windows И macOS**
- Нет открытых критических багов
- Лист **CWS Публикация** — все флажки до P.11

## Листы CWS — порядок работы

1. **CWS Подготовка** — аккаунт, privacy, сборка, деплой
2. **CWS Графика** — скриншоты и иконки
3. **CWS Контент** — копировать тексты в форму Store
4. **CWS Permissions** — обоснования при запросе модерации
5. **CWS Публикация** — пошаговая загрузка в Dashboard

Полное описание RU: файл `08_Полное_описание_RU.txt` (удобно копировать целиком).
