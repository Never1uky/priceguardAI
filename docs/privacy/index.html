2. Какие данные мы обрабатываем

2.1. Данные о товарах и ценах

  • названия, артикулы, URL карточек;
  • текущие и исторические цены, скидки;
  • результаты сравнения между маркетплейсами;
  • список отслеживания и целевые цены;
  • настройки порогов уведомлений.

Где: локально (chrome.storage) и, при входе в аккаунт, в облаке Supabase (tracked_products, при серверном мониторинге — также product_price_history).

2.2. Отзывы и AI-анализ

При AI-анализе (в расширении или в Telegram-боте алертов):

  • собираются тексты отзывов (через браузер и/или сервер: публичные API WB, HTML страниц Ozon/YM);
  • тексты и краткие поля товара отправляются на наш Edge-прокси → провайдерам AI;
  • результат может сохраняться в общем кэше product_cache (TTL около 7 дней) по паре «маркетплейс + идентификатор товара» — без привязки к вашему email.

API-ключи AI не хранятся в расширении.

2.3. Аккаунт (опционально)

Через Supabase Auth: email, UUID пользователя, токены сессии (локально). Пароли в открытом виде мы не храним.

2.4. device_id

Случайный UUID на устройстве: лимиты AI, привязка лицензии, анонимная телеметрия. С личностью не связан, пока вы не вошли в аккаунт.

2.6. Серверный мониторинг цен (Bright Data)

При включённом Telegram-мониторинге сервер периодически запрашивает страницы/данные карточек отслеживаемых товаров. Для площадок с антиботом может использоваться сервис Bright Data Web Unlocker: на сторону Bright Data уходит URL карточки (и получается HTML/контент страницы). Cookies вашего браузера туда не передаются.

Краткий результат цены может кэшироваться (~2 часа, price_scrape_cache).

2.7. Телеметрия

Обезличенные события: метрики поиска, лог AI-запросов (провайдер, успех, длительность), события проверки «оригинал», версия расширения. Не передаём полную историю браузинга и данные карт.

2.8. Платежи Premium

Обрабатывает ЮKassa. Мы получаем статус платежа и данные для выдачи/привязки лицензии, не номер карты.

2.9. Партнёрские метки в ссылках (опционально)

Расширение может добавлять технические параметры партнёра к ссылкам на товары (локальные настройки). Отдельный сбор ПДн для рекламы третьим лицам не ведётся.

2.10. Сайт

Технические cookie / localStorage для работы страниц оплаты и сессии. Маркетинговые рассылки без согласия не отправляем.

5. Сроки хранения

  • аккаунт и лицензия — пока действует аккаунт/подписка и разумный срок после;
  • локальные данные — до удаления расширения или очистки storage;
  • product_cache — около 7 дней;
  • price_scrape_cache — около 2 часов;
  • треды Telegram AI — около 48 часов;
  • служебные логи — обычно до 90 дней, если иное не нужно для безопасности.
