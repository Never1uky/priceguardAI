### Funnel events (P1.1)

Install / `extension_started` / card+marketplace detected / compare_* / comparison_failed / match_* / ai_analysis_* / tracking add-remove / monitoring_refresh / telegram_* / premium_page_opened + trial/checkout/premium.

See `FUNNEL_EVENT_NAMES` in `funnel.ts`.

## Privacy rules (обязательно)

**Никогда не логировать:** URL карточек, полные titles, тексты отзывов, cookies, session tokens, email, chat messages, payment PAN/3DS, Telegram chat id, license keys, product_id на funnel.

**Разрешено:** marketplace enum, boolean flags, plan id, failure_reason whitelist, duration buckets, session id, device/install id only if needed, ext version.

**Remote:** funnel INFO **только** при включённой настройке «Анонимная аналитика продукта» (та же `remoteEnabled`, что и WARN/ERROR cloud). Default off.

### Черновик для RU §телеметрия

> При включённой настройке «Анонимная аналитика продукта» расширение может отправлять на наши серверы обезличенные события воронки (установка, открытие карточки маркетплейса, запуск и результат сравнения цен, использование AI-анализа, добавление в отслеживание, подключение Telegram, открытие Premium). В этих событиях **нет** адресов страниц, названий товаров, текстов отзывов, идентификаторов товара, cookie, адреса электронной почты и содержимого сообщений. Используются технический идентификатор устройства/сессии и версия расширения. Настройку можно выключить в любой момент в разделе «Конфиденциальность». Отдельно (также только по согласию) могут отправляться технические предупреждения и ошибки для диагностики.

CWS Data Use: optional product analytics / diagnostics when user opts in.
