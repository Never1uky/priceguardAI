# P0.2 — First comparison UX walkthrough

**Дата:** 2026-08-20 (UI: 2026-08-20)  
**Код:** `priceguard-ai`  
**Статус:** DONE (UX copy + progress; auto-compare не включали)

## Цель

Пользователь должен быстро понять: «открыл товар → расширение нашло тот же SKU на других площадках».

## Что изменилось (реализация)

| Было | Стало |
|------|--------|
| Primary CTA «Следить за ценой» | **«Сравнить цены»** (+ подпись: в «Мои» + WB/Ozon/Маркет) |
| Pending «Добавляем и ищем…» | **«Добавляем и сравниваем…»** + «Ищем на WB · Ozon · Я.Маркет…» |
| Toggle блок «Следить за ценой» | **«Оповещения о цене»** (только alerts) |
| Table hint без счётчика | **`Ищем на Ozon… 2/3`** via `compare-search-progress.ts` |
| List row «Ищем…» | **`Ищем на Ozon…`** / `Ищем… 1/3` |
| Empty «Мои» про «Следить» | Про **«Сравнить цены»** |

**Не сделано (намеренно):** auto-start compare на scrape; вторая кнопка «только сравнить без track» (один primary CTA).

## Happy path (без аккаунта)

| # | Действие пользователя | Что делает продукт | Loading / UI | Где код |
|---|----------------------|--------------------|--------------|---------|
| 0 | Установка / открытие popup | Onboarding-карточка (один раз) | «Откройте товар на WB/Ozon/Маркете» → «Понятно» | `App.tsx` `ONBOARDING_SEEN_KEY` |
| 1 | Открыть карточку товара на MP | Content scrape / `GET_ACTIVE_TAB_PRODUCT` | «Загрузка товара…» / error | `useLiveProduct`, parsers |

| 3 | Жмёт CTA **«Сравнить цены»** | `addToMyProducts` → track + `ENSURE_COMPARE_PRODUCT` + research | CTA pending + hint 3 MP | `App.tsx` |
| 4 | Редирект на «Мои товары» | Фокус на compare-row | Toast success / warning | `goToMyProducts` |
| 5 | Ждёт сравнение | HiddenBrowser / SERP / cascade / mapping-cache | **«Ищем на Ozon… 2/3»** | `ComparisonTable`, `compare-search-progress` |
| 6a | Успех | Таблица офферов, «Где дешевле» | Цены + статусы verified/probable | |
| 6b | Неоднозначно | Picker «Выберите товар (N)» | Titles + mismatch badge | `ComparisonTable` CandidatePicker |
| 6c | Не найдено | not_found + «Найти на …» | Error short text | |

**Регистрация не обязательна** для first compare. Аккаунт нужен для cloud sync / trial / Premium.

## Сколько кликов до «где дешевле»

Минимум: **2–3** после установки (карточка → popup → «Сравнить цены»).  
Идеал «открыл → сразу видит» **не** делали: compare только по явному CTA.
